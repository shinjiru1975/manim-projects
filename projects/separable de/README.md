# Separable Differential Equations
This Manim project for separable differential equations was my first project after starting out with Manim. I've been live streaming Differential Equations on TikTok for a while, and thought that it might be time to create videos as well.

The `original` folder contains the very first files for this project. In it contains my first pieces of code with Manim, as well as my side comments and reactions when the code began to magically work.

The `v2` folder contains the actual files I used to render the videos. It is more structured, organized, and efficient (with the use of helpers) compared to `original`. 

I recommend that you read the `README.md` files on those folders as well.
