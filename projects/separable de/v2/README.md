# Version 2
Version 2 is the improved version of `original` of this project. It is more organized and structured, based heavily on the code I already made in `original`.

This version heavily utilized animation helpers that Claude AI helped me create in the `common` folder at the root of the project. Helpers are groups of terms and/or animations that combine to form a single method, so instead of writing multiple `self.play` functions to convey an animation idea, you only write one function or fewer than what was originally needed. Among these helpers are:
- `self.morph`,
- `self.derive`,
- `self.copy_down`,
- `self.substitute`,
- etc.

`WORKFLOW.md` was the instructions file that came with the helpers Claude generated, but I don't really read or follow it that much.

It was also during this time that I finally created a GitHub repository to track all changes to this project.
