# Manim ni Shin
[![Static Badge](https://img.shields.io/badge/Follow-fe2c55?style=for-the-badge&logo=tiktok&label=TikTok&labelColor=black)](https://www.tiktok.com/@shinjiru1975)

This project contains the code used in generating the mathematics animation videos by [Shinjiru](https://www.tiktok.com/@shinjiru1975) using [Manim](https://github.com/manimCommunity/manim), a [Phython](https://www.python.org/) library by [3Blue1Brown](https://www.youtube.com/@3blue1brown) for creating beautiful math animations.

# Background
The initiative to learn Manim began on October 13, 2026.

I am a 3rd-Year BS Electrical Engineering student. I became an irregular student after failing Differential Equations on my 2nd Year. 

My comeback game plan was to livestream myself teaching engineering math on [TikTok](https://www.tiktok.com/@shinjiru1975) so I would have genuine motivation of learning to understand concepts instead of learning just to prepare for an exam.

I have been doing this livestreaming thing for a while, so I thought that it might be time to create videos as well, in the same hopeful manner as how 3Blue1Brown makes his.

I have very little experience with programming, so this was a challenging yet fun hobby to do during my leisure.

I am using VS Code as my IDE.
